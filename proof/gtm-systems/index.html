02Improve the motion

Quality-First Prospecting

The original question was whether pickup-likelihood scoring could improve connect rates. The more important result was learning where the prospecting system itself needed to change.

My role· experiment · analysis · diagnosis · iteration
  1. 1 · Hypothesis Improve connect rate score phone numbers by pickup likelihood
  2. 2 · Early signal 17–32% tiny samples · provisional
  3. 3 · Scaled result ~12.5% cumulative ~9% as volume increased team-wide dialing remained ~4–5%
  4. 4 · Diagnosis expands
    • contact quality
    • phone quality
    • targeting
    • enrichment
    • rep execution
    • number reputation
    • adoption
  5. 5 · System changes
    • better sourcing
    • waterfall enrichment
    • weekly ICP / targeting refinement
    • repeatable prospect builds
    • routing + sequencing
    • continued measurement
Built with TitanX · Floqer · Claude Code · g-gremlin · Salesforce · Outreach · Orum

pickup scoring · AI sourcing/enrichment · programmatic list build · CRM matching/routing · sequencing · dialing

Early pilot snapshot

1,450 P1 dials → 182 connects → 93 conversations → ~7 SQLs / meetings

The durable result wasn't one score. It was a better prospecting system.
