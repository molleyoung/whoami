Revenue process / governed handoff

Closed Won Review Agent

A scheduled control point that clears clean deals for fulfillment and returns specific issues for remediation before downstream execution begins.

My role

Control design · deterministic validation · orchestration · exception experience

Risk

Closed Won was a milestone, not proof that a deal was ready.

Fulfillment depends on complete products, dates, billing details, contracts, signatures, addresses, and other operating requirements. A missing or conflicting value discovered downstream creates delay and manual coordination at the most sensitive handoff.

The control needed to catch known issues quickly without turning every clean deal into a manual review queue.

Architecture

A scheduled review with an explicit decision gate.

Salesforce remains the deal and approval home. A scheduled Python validation engine evaluates the Closed Won population, uses deterministic logic for explicit business rules, and applies AI only to narrow interpretation and readable remediation tasks.

Pass path

Clear the clean deal

Write the approved state in Salesforce so shipping, invoicing, provisioning, and other downstream work can proceed.

Issue path

Return a specific fix

Alert the responsible operating channel with remediation guidance, then place the deal back into the review loop.

Control design

Fast for clean deals. Precise for exceptions.

The design separates rules that can be evaluated reliably from context that needs interpretation. It also makes the result operational: a pass changes the deal state, while an issue identifies what must be corrected before recheck.

01

Scheduled population

Review eligible Closed Won deals on a consistent operating cadence.

02

Deterministic first

Encode explicit business requirements as repeatable checks wherever possible.

03

Narrow assistance

Use AI only where interpretation or clearer remediation language adds value.

04

Visible outcome

Keep approval and issue status in Salesforce, the operating system of record.

05

Actionable exception

Tell operators what failed and what is needed instead of returning a generic rejection.

06

Recheck loop

Return corrected deals to the same control so release criteria remain consistent.
